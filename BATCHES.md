# Delamere Farm Build Batches

1. `01_CREATE_SKELETON.cmd` — creates the complete folder/file skeleton.
2. `02_INSTALL_AND_SETUP.cmd` — creates `.env`, installs Node dependencies, initializes SQLite.
3. `03_SEED_DEMO_DATA.cmd` — loads development sample animals, dairy products, and FAQs.
4. `04_START_DEV.cmd` — starts the website on `http://localhost:3000`.

The full source code is already placed in the matching skeleton in the project package.
Use `npm.cmd`, not `npm`, from PowerShell if PowerShell blocks `npm.ps1`.
